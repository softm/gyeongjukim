# 경주김씨 종친회 — 제품 명세

## 1. 한 줄 정의

경주김씨 종친이 계보를 확인하고, 종친회 소식·행사·기록으로 연결되는 모바일·웹 통합 서비스.

## 2. 제품 목표

분산된 족보, 공지, 행사, 연락 정보, 역사 자료를 이해하기 쉬운 화면에서 찾을 수 있게 합니다. 고령 종친은 적은 단계와 큰 글씨로 필요한 업무를 마치고, 젊은 종친은 자신의 가족 관계와 종친회 활동에서 참여 계기를 얻도록 합니다.

이 저장소의 1차 결과물은 **GitHub Pages에서 실행하는 가상 자료 데모**입니다. 실회원 운영을 위한 가입·권한·공동 데이터·문자 발송은 후속 백엔드 단계에 해당합니다. 제공받아 검수한 족보 원본이 없으므로 실제 계보나 공식 분파 목록을 임의로 확정하지 않습니다.

## 3. 사용자와 핵심 과업

| 사용자 | 해결할 과업 | 화면·기능 기준 |
| --- | --- | --- |
| 일반 종친 | 본인·가족 찾기, 공지 읽기, 행사 참석 여부 등록 | 검색 조건이 명확하고 결과에서 다음 행동이 보여야 함 |
| 종친회 관리자 | 가입 심사, 조직·담당자 관리, 공지 운영 | 처리할 신청과 승인 근거·이력을 함께 확인 |
| 족보·자료 관리자 | 자료 검수, 계보 변경 검토, 출처 연결 | 원본·수정 요청·결정 이유를 분리 보존 |
| 행사 운영자 | 일정 생성, 신청·마감·참석 집계 | 행사별로 허용된 회원 정보만 조회·수정 |
| 콘텐츠 관리자 | 역사 자료·소식 게시와 수정 | 출처·작성일·검수 상태·공개 범위를 명시 |
| 고령 종친 | 공지 확인, 참석 선택, 도움 요청 | 큰 글씨, 충분한 클릭 영역, 단순한 용어·입력 |
| 젊은 종친 | 가족 관계 이해, 기록 공유, 행사 탐색 | 모바일 탐색, 짧은 소개, 공유 가능한 공개 자료 |

## 4. 정보 구조

| 메뉴 | 주요 내용 | 주요 행동 |
| --- | --- | --- |
| 홈 | 종친회 소개, 중요 공지, 가까운 행사 | 공지 열기, 족보 검색 시작, 행사 보기 |
| 족보 | 이름·분파·세대 조건, 검색 결과, 인물·관계 | 검색·초기화, 인물 선택, 가족 관계 탐색 |
| 행사 | 시향·총회·문화 활동 일정, 상세 안내 | 일정 확인, 참석 여부 선택 |
| 소통 | 공지·질문·후기 등 게시글 | 목록·상세 보기, 글 작성 |
| 역사·문화 | 계보 읽기, 기록 보존, 역사 자료 | 자료 열기, 출처 확인 |
| 내 정보·설정 | 보기 설정, 저장 상태, 서비스 안내 | 큰 글씨 변경, 브라우저 데이터 관리 |

메뉴명은 실제 UI와 함께 다듬습니다. 한 종친회 안에서 본관이 항상 경주로 고정된다면 본관 검색 필터를 반복 노출하지 않고 이름·분파·세대처럼 구분에 유용한 조건을 우선합니다.

동명이인은 이름만으로 합치지 않습니다. 인물 ID와 계보 위치·출처를 함께 사용하며, 촌수·관계 명칭은 확인된 부모·자녀 관계에서 계산 가능한 범위만 제공합니다. 배우자·입양·서로 다른 족보 기준이 포함된 경우 해석 근거를 별도로 표시합니다.

## 7. 화면·사용성 수용 기준

1. 검색 결과가 없으면 조건을 지우거나 바꿀 수 있는 동작을 제공합니다.
2. 목록에서 상세로 이동했다 돌아오면 기존 검색 맥락을 유지합니다.
3. 참석·글 작성·설정 저장이 성공했는지 사용자에게 즉시 알립니다.
4. 저장이 실패하면 성공으로 표시하지 않고 다시 시도할 수 있게 안내합니다.
5. 큰 글씨와 좁은 화면에서 버튼·본문·대화상자가 잘리지 않아야 합니다.
6. 키보드로 주요 메뉴와 대화상자를 조작하고 초점을 확인할 수 있어야 합니다.
7. 운영 데이터와 가상 데이터를 혼동하게 만드는 승인·공식·보호 완료 문구를 사용하지 않습니다.
8. 사용자 입력을 HTML로 그대로 실행하지 않습니다. 링크는 허용한 방식으로만 생성합니다.

## 8. 핵심 지표 정의

다음은 요청된 **출시 후 6개월 목표**이며 현재 실적이 아닙니다. 공개 체험 앱에는 실회원 분석 수집을 연결하지 않았습니다. 운영 도입 때 측정 동의·집계 기준·제외 대상을 확정합니다.

| 지표 | 목표 | 권장 분자·분모 |
| --- | --- | --- |
| 회원 가입자 | 1,000명 이상 | 중복·시험 계정을 제외한 누적 가입 계정 |
| 승인 완료율 | 70% 이상 | 승인 완료 계정 ÷ 심사 대상 가입 계정 |
| 월간 활성 비율 | 40% 이상 | 월 1회 이상 핵심 행동한 승인 회원 ÷ 해당 월 이용 가능한 승인 회원 |
| 족보 검색 성공률 | 90% 이상 | 원하는 결과를 찾았다고 확인한 검색 과업 ÷ 결과 확인에 응답한 검색 과업; 응답률 별도 공개 |
| 행사 신청 전환율 | 30% 이상 | 참석 신청한 고유 회원 ÷ 신청 가능한 행사 상세를 본 고유 회원 |
| 참석 여부 등록률 | 50% 이상 | 참석·불참 등을 등록한 고유 회원 ÷ 신청 가능한 행사 상세를 본 고유 회원 |
| 공지 열람률 | 70% 이상 | 공지를 연 고유 대상 회원 ÷ 공지 발행 당시의 수신 대상 회원 |
| 문의 만족도 | 80% 이상 | 만족으로 응답한 처리 문의 ÷ 평가 응답 문의; 평가 척도 사전 확정 |
| 주요 기능 오류율 | 1% 미만 | 시스템 오류로 실패한 유효 요청 ÷ 전체 유효 요청 |
| 커뮤니티 참여 | 추이 관찰 | 월별 글·댓글·작성자 수; 운영자 게시와 일반 참여 구분 |
| 세대별 사용성 | 별도 관찰 | 자발적으로 제공한 연령 구간의 활성 비율·핵심 과업 완료율 |

검색 결과가 한 건 나왔다는 것만으로 성공으로 계산하지 않습니다. 행사 신청 전환율과 참석 여부 등록률은 분모를 일치시키고, 불참 등록이 후자에만 포함됨을 명확히 합니다.
